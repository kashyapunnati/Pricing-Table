# Pricing Table

A responsive pricing table created as part of the VEDA Technology Web Development Internship.

## 📝 Description

This project is a responsive pricing table that displays three different subscription plans.

Each pricing card includes:
- Plan name
- Monthly price
- Feature list
- Call-to-action button

The Professional plan is highlighted as the **Popular** plan.

## 🎯 Objective

The main objective of this task is to practice:

- CSS Flexbox layout
- Responsive web design
- CSS hover effects
- Borders and shadows
- Creating attractive pricing cards

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Media Queries

## 💻 Features

- Three pricing plans:
  - Basic
  - Professional
  - Premium
- Popular plan highlighted
- Responsive layout
- Responsive stacking on small screens
- Button hover effects
- Card hover effects
- Clean and simple user interface
